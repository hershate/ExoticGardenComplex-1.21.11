# ExoticGardenComplex 1.0.0（Minecraft 1.21.11）

> 发布日期：2026-07-30
> 目标 Minecraft：1.21.1 ~ 1.21.11（paper-api 1.21.1，Java 16 编译 / JDK 21 构建）
> 依赖：粘液科技 REF（`com.github.slimefun:Slimefun:4.9.5`，第三方非官方分支 [hershate/Slimefun4.1](https://github.com/hershate/Slimefun4.1)）
> 产物：`ExoticGardenComplex-1.21.11-1.0.0.jar`
> 静态测试：9 维度 50/50 通过

首个语义化版本。在 REF 迁移（编译通过）基础上，完成三轮安全 / 稳定性加固。

## 改动概要

### 第一轮：致命崩溃 / 安全 / 稳定（详见 [note/hardening.md](../hardening.md) 一~六）
- **致命崩溃 5 项**：VersionedPotionEffectType null、getOutputSlots UnsupportedOperationException、PlayerAlcohol 清空数据段、ExoticCommand NPE、PlayerListener.move NPE
- **机器安全**：canOpen 权限、配方匹配数量校验（防刷物品）、新增 MachineIO 替代异步 Bukkit.createInventory、pushSubItems 槽位修复、ThreeInputGUI break inv null
- **监听器**：PlantsListener 异步回调回主线程、onGenerate nextInt 边界、clickedBlock/hand null、死代码清理
- **com.be 安全**：移除 `login.allow` 绕过、spawn-on-join 配置、命令 world/null/返回值、RegistryHandler 懒加载 + saveSchematic null
- **schematics/items**：Schematic null/维度校验、NBT OOM/SOE 防护、Kitchen 强转防护、GrassSeeds 领地保护
- **健壮性**：initDataFromYAML 路径、sendDrunkMessage、saveSchematic null、FoodListener 连点、BE 草掉落过滤

### 第二轮：UUID / bstats / 配方（详见 hardening.md 七~八）
- **醉酒数据改用正版验证 UUID 存储** + 旧"玩家名"数据自动迁移
- **移除 bstats 匿名统计**（代码 / pom / test.sh）
- MagicalEssence 8→1 破坏配方改 1→1、Crook 新树叶显式映射、死代码清理、onDisable 不置空集合

### 第三轮：高负载并发与物品流转（详见 hardening.md 九）
- 机器 `processing`/`progress` 改 `ConcurrentHashMap`
- 机器完成 `fits` 检查（防产物凭空消失）、tick 残留清理（防爆炸 NPE / 内存泄漏）
- Kitchen 消耗 `matchCount`（防误吞）、treeFruits 补全 BE 树（右键采集修复）+ dropFruitFromTree O(1) 优化
- GoldKeLa `FERTILIZER_WHEAT` 缺失防护

## 构建与测试

```bash
# 1. 一次性安装 REF 到本地仓库
cd REF/Slimefun4.1 && mvn clean install -DskipTests
# 2. 编译附属 → target/ExoticGardenComplex-1.21.11-1.0.0.jar
cd ../.. && mvn clean package -DskipTests
# 3. 静态测试（9 维度 50/50）
bash test/test.sh
```

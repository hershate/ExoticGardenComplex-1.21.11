# ExoticGardenComplex 1.2.0（Minecraft 1.21.11）

> 发布日期：2026-07-31
> 目标 Minecraft：1.21.1 ~ 1.21.11（paper-api 1.21.1，Java 16 编译 / JDK 21 构建）
> 依赖：粘液科技 REF（`com.github.slimefun:Slimefun:4.9.5`，第三方非官方分支 [hershate/Slimefun4.1](https://github.com/hershate/Slimefun4.1)）
> 产物：`ExoticGardenComplex-1.21.11-1.2.0.jar`
> 静态测试：10 维度 51/51 通过；离线基准：5 项等价性断言全 PASS。

**机器 tick 性能优化版本**。在 1.1.0（idle 分支配方签名缓存、`MachineIO.fits` 零 clone、采集查表索引）
基础上，针对 1.1.0 之后**仍存在的最大热点——加工中机器每 tick 的进度条显示更新**做优化，
**不降低安全性/稳定性/兼容性、不改变玩家可见行为**。

## 改动概要（详见 [note/perf-optimization.md](../perf-optimization.md) 六 与
[report/perf](../report/perf/2026-07-31-machine-tick-viewer-gating.md)）

### 机器 tick 进度条按观看者门控（主）
- `DefaultGUI` / `ThreeInputGUI` 的 processing 分支：把整段进度条重建（`clone` + meta +
  `getProgress`/`getTimeLeft` 的 StringBuilder/translate + `replaceExistingItem`）用 `menu.hasViewer()`
  包起来。**无人查看时跳过整段**（常态），有人查看时与原来完全相同。
- 能量消耗与进度递减保持在门控**之外**，始终执行（游戏逻辑）。
- 基准：无人查看 ~225→~2 ns（**约 75–118×**）。

### 已解析 Slimefun 物品按方块缓存（次）
- 新增 `sfItemCache`，避免每加工机器每 tick 调 `BlockStorage.check`。清理与
  `processing`/`progress`/`idleMatchCache` 同生命周期。基准：6.9→4.4 ns（保守，真实收益更大）。

### 稳定性修复
- 修复 `ThreeInputGUI` 第二构造器（带 `recipeOutput`）`BlockBreakHandler` 漏清 `idleMatchCache`
  的内存泄漏（第一构造器有清，第二构造器原本没有），并补上 `sfItemCache.remove`。

### 测试基建
- `benchmark/` 新增 `SimMenu` 模型 + tick 显示构建（旧总是 vs 新门控）+ SFItem 解析
  （`BlockStorage.check` vs 缓存）的旧新对照。
- 离线基准等价性断言由 **3 项扩至 5 项**（新增“进度条门控等价”“SFItem 缓存等价”）。

## 构建与测试

```bash
# 1. 一次性安装 REF 到本地仓库
cd REF/Slimefun4.1 && mvn clean install -DskipTests
# 2. 编译附属 → target/ExoticGardenComplex-1.21.11-1.2.0.jar
cd ../.. && mvn clean package -DskipTests
# 3. 静态测试（含基准正确性）
bash test/test.sh
# 4.（可选）运行基准并保存结果
bash benchmark/run.sh save
```

## 兼容性

- 公开 API（`getInputSlots`/`getOutputSlots`/`fits`/`pushMainItems`/`getSubRecipes`/`getProgressBar`、
  配置文件格式、物品/配方 id 等）**完全不变**。
- 对**打开 GUI 的观看者**显示完全不变（有人查看时构建逻辑原样保留）。
- 5 项离线等价性断言（match / fits / 进度条门控 / SFItem 缓存）全 PASS，证明行为不变。
- 门控反而**减少**了 ticker 在异步线程对 Bukkit 库存的 `replaceExistingItem` 调用次数（更安全）。

## 已知遗留（同 1.0.0 / 1.1.0）

- 未做实机运行回归；建议真实 Paper 1.21.1+ 服务器负载观察（多台加工机器、长时间运行）。
